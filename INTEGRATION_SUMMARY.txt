INTEGRATION APPROACHES:
================================================================================

Approach 1: Direct Pipeline Integration
- Use the Python API directly in your application
- Best for: Single-machine deployments, development, testing
- Example: examples/simple_integration.py

Approach 2: Remote API Integration
- Deploy model as a service, call via HTTP API
- Best for: Production deployments, microservices architecture
- Example: examples/api_client_integration.py

Approach 3: Multi-GPU Distributed Inference
- Scale across multiple GPUs for production workloads
- Best for: High-throughput production deployments
- Example: run_parallel.py (already existed)
